# קטאן (משחק מעריצים)

משחק דפדפן מקומי עם בוטים. הקוד מופץ תחת GPL-3.0; ראו [LICENSE](LICENSE).

## AI

`catan-alphabeta.js` הוא עיבוד מקומי של AlphaBetaPlayer ושל פונקציית ההערכה של [Catanatron מאת Bruno Collazo](https://github.com/bcollazo/catanatron), לפי המקור המצוין בראש הקובץ. הקובץ המקורי והעיבוד כפופים ל-GPL-3.0. הקובץ `catan-ai-adapter.js` מחבר את המנוע ללוח ולמצב המשחק הזה. קובצי המנוע נטענים מהאתר עצמו, ללא שרת או שירות חיצוני.

הבוטים משתמשים בחיפוש בעומק 2 לבחירת בנייה והחלפה עם הבנק, ובחיפוש בעומק 1 להצבת יישוב פתיחה. רכישת קלפי פיתוח, הפעלת אבירים ומסחר בין שחקנים נשארים בלוגיקה הקלאסית של המשחק. החלפת 4:1 עם הבנק מוצעת לחיפוש רק כשהיא משלימה בנייה מידית; נמלים (2:1/3:1) מותרים תמיד. ההערכה מתחשבת ביריב החזק ביותר, לא רק בשחקן הבא בתור. סימולציה של הטלה עתידית מחשבת את הסתברויות 2–12. פעולות קלפי פיתוח, מסחר בין שחקנים ומהלכי שודד עדיין משתמשים בחוקי המשחק ובשיטות הקיימות. אירוע 7 בסימולציה הוא קירוב, והסימולציה אינה מנוע קטאן מלא. הבוט אינו מקבל מידע על סדר הקלפים העתידי. אם טעינת מודול החיפוש נכשלת, האלגוריתם הקודם נשאר פעיל.

להרצת בדיקות מתאם: `node --experimental-default-type=module tests/ai-adapter.test.mjs`
